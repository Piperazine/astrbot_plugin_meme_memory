# 表情记忆（astrbot_plugin_meme_memory）

给 AstrBot 的表情包加一层**记忆**：会收藏、会理解、会淡忘，聊到合适的时候自己配一张。

市面上大多数表情包插件是"库"——只进不出，靠手动清理或固定容量（常见 20–30 张）卡住。
这个插件把**时间**当变量：每张图有强度，不用就衰减，久到一定程度被遗忘，再出现还能复活。

---

## 它怎么工作

### 1. 收图：只收"确实是表情包"的

三级判定，逐级降成本：

| 级别 | 依据 | 成本 |
|---|---|---|
| L1 协议线索 | OneBot 的 `sub_type=1`、`summary` 含"表情"、`mface` 段 | 0 |
| L2 图片特征 | 透明通道、动图、接近方形、体积小；截图/照片反向扣分 | 0 |
| L3 视觉模型 | 只对 L2 拿不准的图问一次"这是表情包吗" | 花钱 |

同一条消息里的普通截图会被 L2 的负分挡掉，不会污染图库。

**GIF 动图**：存原文件不转码；识别时抽 3 帧横向拼成一张再送模型，否则"猫在动"和"猫在躺"分不出来。

### 2. 理解：画面 + 图中文字 + 语境

对每张入库的图调用一次视觉模型，同时拿到：

- `desc` 画面里是什么
- `ocr` 图上写的字
- `ctx_tags` 这张图在**这个语境**里表达什么（嘲讽 / 无奈 / 自嘲 / 认同……）

语境只取**发送者本人**的消息：别人的话默认不算，除非是"被引用的那条"（最强证据）或"紧邻的上一句"（弱参考）。
群里中间夹着别人聊天时，不会被带偏。

同一张图在不同语境反复出现时，标签按次数累加（`{"嘲讽": 3, "无语": 2}`），自然会收敛到主要用法。

### 3. 遗忘：强度与半衰期

每张图有一个强度值，默认**半衰期 3 天**（每天 ×0.794）：

| 事件 | 变化 |
|---|---|
| 收藏 | 强度 = 1.0 |
| 再次看到 | +0.35 |
| 被使用 | +0.25 |
| 不碰 | 每天 ×0.794 |

状态机：

| 状态 | 含义 |
|---|---|
| 观察期（默认 6 小时） | 刚收的图不许主动发，避免"你发一张她立刻回一张" |
| 活跃（≥0.35） | 可被检索、可被发送 |
| 沉睡（0.08–0.35） | 不主动发，但仍能被搜到 |
| 遗忘（<0.08 且持续 3 天） | 移出索引；**文件保留 30 天**再物理删除 |

已遗忘的图再次出现时**直接复活到 1.5**，跳过观察期——像"想起来了"，而不是"重新认识"。

空库不碰的话，大约第 12 天被遗忘；常用的靠"再看到/被使用"能一直活着。
所以图库会长期稳定在二三十张"常用的"，而不是无限膨胀。

### 4. 发送：按语义挑，不相关就不发

她准备回复时，插件会：

1. 取"对方说的话 + 回复开头"做向量查询（bge-m3）
2. 和图库里每张图的语义向量算相似度
3. 叠加强度权重（最终分 = 相似度 ×0.7 + 强度 ×0.3）
4. **相似度低于阈值（默认 0.35）一张都不发**
5. 优势明显取第一名；前几名几乎并列才随机

另外还有硬约束：同一张图 24 小时冷却、同会话 10 分钟冷却、每天最多 5 张。

> 设计取向：**宁可少发，也不发错的**。一条消息配一张不对味的图，比不配更像机器人。

## 安装

### 方式一：面板上传

AstrBot 面板 → 插件 → 从文件安装 → 选 `astrbot_plugin_meme_memory.zip` → 启用 → 重载。

### 方式二：手动

```bash
cd /opt/astrbot/instance/data/plugins/
unzip astrbot_plugin_meme_memory.zip
# 目录名必须是 astrbot_plugin_meme_memory
```

### 依赖

**零额外依赖**。用到的 `sqlite3` / `hashlib` 是标准库，`Pillow` 由 AstrBot 自带。

数据目录：`data/plugin_data/sticker_memory/`（`stickers.db` + `stickers/` 原图）。
插件更新不会清掉它。

---

## 配置

面板里都能改，重要的几项：

| 配置 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总开关 |
| `half_life_days` | 3 | 半衰期（天）。2 忘更快，7 更慢 |
| `max_stickers` | 100 | 容量上限，超了淘汰最弱+最久没出现的 |
| `observe_hours` | 6 | 新图观察期（小时） |
| `analysis_enabled` | true | 是否调视觉模型理解。**关掉就只能随机发图** |
| `analysis_daily_limit` | 60 | 每日视觉模型调用上限 |
| `retrieval_min_similarity` | 0.35 | 最低相似度。调高更保守 |
| `proactive_enabled` | true | 是否允许主动配图 |
| `proactive_daily_limit` | 5 | 每天最多几张 |
| `collect_from_all` | true | 收所有人的图；关掉只收主人 |

---

## 成本

- **视觉模型**：每张新图一次调用（几百 token）。同一张图重复出现会再分析一次用于累积语境标签，受 `analysis_daily_limit` 限制。
- **嵌入**：bge-m3，通常免费额度就够。
- **发送**：不额外花钱（图是直接发出去的）。

不想花就把 `analysis_enabled` 关掉——但那样她只能按强度随机发图，经常牛头不对马嘴。

---

## 已知限制

1. **判定靠 OneBot 字段**。不同适配器给的字段不同；拿不到 `sub_type` / `summary` 时会退化到图片特征 + 视觉模型，准确率会降。
2. **长时衰减没法速测**。半衰期 3 天的效果要真跑几天才看得出来。
3. **群聊里会存别人的图**（若 `collect_from_all=true`）。介意的话关掉。
4. **主动配图是"追加在回复后"**，不是替换；她本来就发了图时可能叠加。
5. **`mface`（商城表情）** 能否取到原图取决于适配器。

---

## 可选联动

如果同时装了会写 `data/plugin_data/_shared/memewiki_hits.json` 的梗百科类插件，
本插件会读取其中"刚才命中了什么梗、带哪些情绪标签"，给候选图按标签重合度加权。

**不装也完全正常**——读不到就当没有。

对应配置：`bridge_enabled` / `bridge_max_age_seconds` / `meme_tag_boost`。

## 回滚

面板禁用即可，数据保留。

彻底删除：

```bash
rm -rf data/plugins/astrbot_plugin_meme_memory
rm -rf data/plugin_data/sticker_memory
systemctl restart astrbot
```
